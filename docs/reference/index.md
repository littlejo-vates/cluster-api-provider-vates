# Reference

Reference pages are for looking things up, not for reading end to end. They
document the objects this provider introduces, the fields they accept, and the
conventions behind them.

- **[Custom resources](crds/index.md)** — the four CRDs, and a page per kind.
- **[Bootstrap payload](bootstrap.md)** — how the provider decides what to do
  with a `Machine`'s bootstrap data.
- **[Cluster templates](templates.md)** — the shipped templates and their layout.

For the meaning behind these objects, see [Concept](../concept/index.md). For
tasks, see [Guides](../guides/providers/kubeadm.md) and
[Getting started](../getting-started/installation.md).
